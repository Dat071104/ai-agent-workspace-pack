# Risk Register / Danh sach rui ro

| Risk ID | Severity | Likelihood | Area | Description | Mitigation | Status |
| --- | --- | --- | --- | --- | --- | --- |
| RISK-0001 | Medium | Low | Embedded layout | Legacy flat-copy embeds can still collide with host paths such as scripts/, .codex/, and .claude/. | Use `--embedded-folder ai-agent-workspace-pack` for new installs; retain flat mode only for compatibility. | Mitigated |
| RISK-0002 | Low | Medium | Harness discovery | Codex/Claude/Gemini may require lightweight root entry files even when all pack content is namespaced. | Root `AGENTS.md` carries a managed prose block (DEC-0006), not an `@path` line; `CLAUDE.md`/`GEMINI.md` are created only if absent and import the root file first. | Mitigated |
| RISK-0003 | High | High | Harness discovery | A namespaced install buries `.codex/agents/`, `.claude/agents/`, and `.claude/skills/` one level down, where no harness auto-discovers them; the four subagents and nine team skills silently disappear while AGENTS.md still promises them. | Installer generates marked root pointers whose paths resolve into the pack folder; verified by golden test and a scratch install. Codex discovery confirmed by file placement, not by a Codex run. | Mitigated |
| RISK-0006 | Low | Medium | Pack drift | A project cannot tell it is running an older pack revision without a source pack to compare against; `session_start` reports the stamp but cannot claim staleness. | `PACK_VERSION` records revision and install date; `embed_pack.py --update` reports `old -> new` when refreshing. | Accepted |
| RISK-0005 | Medium | Medium | Bootstrap | An install can stop at the missing-bridge warning: ops and adapters exist but no root `AGENTS.md` line, so no harness reads the pack. | The warning prints the exact one-line command; prepending a host file stays opt-in by design. | Accepted |
| RISK-0004 | Low | Medium | Code graph | A legacy flat embedded root still indexes its own pack scripts, because a flat host and a pack source checkout share the same markers. | Root-level exclusion removed (DEC-0004); `scripts/migrate_pack.py` converts a flat install to the namespaced layout, after which the exclusion is unambiguous. | Mitigated |
| RISK-0007 | Medium | Medium | Harness correctness | No test drives a real harness. The suite asserts the bytes Codex, Claude Code and Gemini CLI would each load, which cannot catch a change in how one of them loads files. | Assertions moved from filesystem shape to per-harness effective content; the v2 bridge is prose, so it survives a harness that expands no imports at all. | Accepted |
| RISK-0008 | Low | Low | Language coverage | The code graph indexes Python and JS/TS only. A Go, Rust or Java repository gets memory, protocol and hygiene but no symbol graph. | One suffix list (DEC-0007) so no such repo is reported stale for files the scanner will never index; the boundary is stated in the README. | Accepted |
